Проект Deep версии 7.2.0 на чистом JavaScript

## Установка


```bash
npm install deep7
```

Или

```bash
# Клонирование репозитория
git clone <repository-url>
cd deep
npm ci
```

## Подключение

```js
import deep from 'deep7';
```
