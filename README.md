# Deep7

Deep7 - это универсальная ассоциативная система для работы с данными и событиями. Проект представляет собой библиотеку для JavaScript/TypeScript, которая обеспечивает ассоциативную ссылочную модель данных с поддержкой событий.

## Описание

Deep7 предоставляет механизм для создания, связывания и управления объектами в памяти с помощью ассоциативных связей. Основные возможности:

- Создание объектов с уникальными идентификаторами
- Установление типизированных связей между объектами
- Подписка на события изменений в графе объектов
- Выборка объектов по критериям (select)
- Единообразная система событий для всех операций

## Основные концепции

- **Deep** - основной класс, представляющий ассоциативную сущность
- **Memory** - класс для хранения отношений между объектами
- **On** - класс для работы с событиями

## Установка

```bash
npm install deep7
```

## Использование

```javascript
import { Deep } from 'deep7';

// Создание нового экземпляра Deep
const deep = Deep.new();

// Создание типов
const Person = new deep();
const City = new deep();
const LivesIn = new deep();

// Создание экземпляров
const john = new Person();
const moscow = new City();

// Создание связи
const johnsHome = new LivesIn();
johnsHome.from = john;
johnsHome.to = moscow;

// Подписка на события
john.on(event => {
  console.log('Событие для John:', event);
});

// Выборка объектов
const peopleInMoscow = deep.select({ 
  type: Person,
  from: { type: LivesIn, to: moscow }
});

// Работа с результатами выборки
console.log('Количество людей в Москве:', peopleInMoscow.size);
```
