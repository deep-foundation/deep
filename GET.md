# Get

Универсальный метод `get` предоставляет унифицированный способ получения элементов по ключу или индексу из различных типов данных. Это удобный и мощный инструмент для доступа к данным любого типа без необходимости знать конкретную реализацию.

[Результаты бенчмарков →](./gets/get.benchmark.md)

## Обзор

Метод `get` обеспечивает доступ к элементам различных типов данных:
- Элементам массива по индексу
- Символам строки по индексу
- Значениям Map по ключу
- Элементам Set по индексу
- Свойствам объекта по ключу
- Цифрам числа по индексу

## Синтаксис

```javascript
deep(data).get(key)
```

### Параметры

- `key` - ключ или индекс элемента, который нужно получить.

### Возвращаемое значение

Значение элемента по указанному ключу или индексу, либо `undefined`, если элемент не найден.

## Примеры использования

### Доступ к элементам массива

```javascript
import deep from 'deep7';

const arr = [10, 20, 30, 40, 50];
const a = deep(arr);

console.log(a.get(0)); // 10
console.log(a.get(2)); // 30
console.log(a.get(10)); // undefined (индекс за пределами массива)
```

### Доступ к символам строки

```javascript
const str = 'hello';
const a = deep(str);

console.log(a.get(0)); // 'h'
console.log(a.get(3)); // 'l'
console.log(a.get(10)); // undefined (индекс за пределами строки)
```

### Доступ к значениям Map

```javascript
const map = new Map([
  ['name', 'John'],
  ['age', 30],
  ['city', 'New York']
]);
const a = deep(map);

console.log(a.get('name')); // 'John'
console.log(a.get('age')); // 30
console.log(a.get('country')); // undefined (ключ не существует)
```

### Доступ к элементам Set по индексу

```javascript
const set = new Set([5, 6, 7, 8]);
const a = deep(set);

console.log(a.get(0)); // 5
console.log(a.get(2)); // 7
console.log(a.get(10)); // undefined (индекс за пределами Set)
```

### Доступ к свойствам объекта

```javascript
const obj = { name: 'John', age: 30, city: 'New York' };
const a = deep(obj);

console.log(a.get('name')); // 'John'
console.log(a.get('age')); // 30
console.log(a.get('country')); // undefined (свойство не существует)
```

### Доступ к цифрам числа по индексу

```javascript
const num = 12345;
const a = deep(num);

console.log(a.get(0)); // 1
console.log(a.get(2)); // 3
console.log(a.get(10)); // undefined (индекс за пределами числа)
```

## Особенности и ограничения

1. Метод возвращает `undefined` для ключей или индексов, которые не существуют.
2. Для Set элементы доступны только по неотрицательным целочисленным индексам.
3. Для числовых значений происходит преобразование числа в строку и затем доступ к цифрам по индексу.
4. Для `null` и `undefined` всегда возвращается `undefined` независимо от ключа.

## Производительность

В большинстве случаев метод `get` имеет производительность, близкую к прямому доступу к элементам. Наибольшие накладные расходы наблюдаются при работе с `Set`, поскольку для доступа по индексу требуется линейный проход по элементам.
