# Association

Ключевой класс библиотеки, предоставляющий функциональность для создания и управления ассоциативными связями между данными. `Association` обеспечивает проксирование свойств, специальные методы доступа и интеграцию с системой событий.

## Обзор

`Association` — это универсальный класс для создания гибких ассоциативных сущностей с расширенным механизмом проксирования. Класс обеспечивает простой и мощный способ связывания данных, методов и поведения.

## Основные особенности

- **Оборачивание объектов**: любой объект или значение можно обернуть в `Association`
- **Динамическое определение методов**: добавляйте методы до или после создания
- **Мощное проксирование**: гибкая модель обработки операций get, set и apply
- **Статические методы**: общие методы для всех экземпляров через `Association._proxy`
- **Кеширование функций**: повышение производительности при многократном обращении

## Конструктор

```javascript
import deep from 'deep7';
const a = deep(self, methods);
```

## Свойства экземпляра

- `a.this` - оборачиваемый объект или значение
- `a._proxy` - Map с методами и свойствами экземпляра
- `a.temp` - объект для временного хранения данных и кеширования функций

## Статические свойства

- `Association._proxy` - Map с общими методами для всех экземпляров, содержит ссылку на себя по ключу _proxy

## Примеры использования

### Создание динамических обработчиков с моделью (ass, op, args)

Одна из самых мощных возможностей `Association` — создание динамических обработчиков, используя модель (ass, op, args), которая позволяет определить поведение метода для разных операций.

```javascript
// Создание метода сложения чисел с помощью модели (ass, op, args)
const a = deep();

// Такой ключ будет доступен только в рамках этого экземпляра
a.doIt = (ass, op, args) => {
  if (op === 'get') {
    // При операции 'get' создаем/возвращаем кешированную функцию в temp
    return ass.temp.doIt = ass.temp.doIt || ((...args) =>
      ass._proxy.get('doIt')(ass, 'apply', args)
    );
    // Не забыть return, он обязателен ;)
  } else if (op === 'apply') {
    // При операции 'apply' выполняем сложение аргументов
    return args[0] + args[1];
  } else {
    // Обработка неизвестных операций
    throw new Error(`unexpected op=${op}`);
  }
};

// Вызов метода
console.log(a.doIt(2, 3)); // 5
```

### Метод с поддержкой операции set

```javascript
// Создаем метод, который поддерживает операцию 'set'
const a = deep();
let lastValue = null;

a.configurable = (ass, op, value) => {
  if (op === 'get') {
    return ass.temp.configurable = ass.temp.configurable || ((...args) =>
      ass._proxy.get('configurable')(ass, 'apply', args)
    );
  } else if (op === 'set') {
    // Обработка операции установки значения
    lastValue = value;
    return true;
  } else if (op === 'apply') {
    // Возврат текущего значения при вызове как функции
    return lastValue;
  } else {
    throw new Error(`unexpected op=${op}`);
  }
};

// Установка значения
a.configurable = 'newValue';

// Получение значения через вызов метода
a.configurable(); // "newValue"
```

### Счетчик с внутренним состоянием

```javascript
// Создаем метод-счетчик с внутренним состоянием
const a = deep();

// Инициализируем состояние счетчика в temp
a.temp.counterState = { value: 0 };

a.counter = (ass, op, args) => {
  if (op === 'get') {
    return ass.temp.counter = ass.temp.counter || ((...args) =>
      ass._proxy.get('counter')(ass, 'apply', args)
    );
  } else if (op === 'apply') {
    const [increment = 1] = args;
    ass.temp.counterState.value += increment;
    return ass.temp.counterState.value;
  } else {
    throw new Error(`unexpected op=${op}`);
  }
};

// Использование счетчика
a.counter(); // 1
a.counter(5); // 6
a.counter(); // 7
```

## Взаимодействие с другими компонентами

`Association` разработан для интеграции с другими компонентами системы Deep:

- **Events**: добавляйте поддержку событий к ассоциациям
- **Memory**: создавайте ассоциативную память для хранения отношений
- **Lifecycle**: управляйте жизненным циклом ассоциаций

## Советы по производительности

1. Используйте статическое хранилище `Association._proxy` для общих методов, то что добавлено туда доступно во всех экземплярах
2. Кешируйте функции в `temp` объекте экземпляра
3. Избегайте многократного создания одинаковых ассоциаций
4. Определяйте методы с поддержкой операций 'get', 'apply' и 'set' для максимальной гибкости

## Типичные проблемы и решения

### Проблема: Утерянное кеширование функций

**Симптом**: При каждом доступе к методу создается новая функция

**Решение**: Убедитесь, что вы кешируете функцию в объекте temp во время операции 'get'

```javascript
// Неправильно
a.method = (ass, op, args) => {
  if (op === 'get') {
    // Не кешируем функцию в temp
    return (...args) => ass._proxy.get('method')(ass, 'apply', args);
  } else if (op === 'apply') {
    return args.reduce((sum, val) => sum + val, 0);
  }
};

// Правильно
a.method = (ass, op, args) => {
  if (op === 'get') {
    // Кешируем функцию в temp
    ass.temp.method = ass.temp.method || ((...args) =>
      ass._proxy.get('method')(ass, 'apply', args)
    );
  } else if (op === 'apply') {
    return args.reduce((sum, val) => sum + val, 0);
  }
};
```
