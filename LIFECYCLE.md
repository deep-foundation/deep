# Жизненный цикл (Lifecycle)

`Lifecycle` предоставляет механизм для управления жизненным циклом ассоциаций, включая их создание, удаление и перезагрузку, а также возможность добавления пользовательских обработчиков для этих событий.

## Производительность

**Информация о системе:**

- clk: ~1.12 GHz
- cpu: Intel(R) Core(TM) i9-9880H CPU @ 2.30GHz
- runtime: node 23.4.0 (x64-darwin)

| Тест | Среднее время выполнения | Операций в секунду |
|------|--------------------------|--------------------|
| Создание ассоциации + onNew | 1.96 s/итер | 0,51 опер/сек |
| Создание и удаление ассоциации (onNew + onKill) | 2.13 s/итер | 0,469 опер/сек |
| Вызов функции kill | 1.98 s/итер | 0,505 опер/сек |
| Перезагрузка ассоциации (reload) | 17.84 ms/итер | 56,054 опер/сек |
| Получение количества живых ассоциаций (all.this.size) | 27.51 ms/итер | 36,35 опер/сек |
| Пользовательский callback в onNew | 203.16 ms/итер | 4,922 опер/сек |
| Пользовательский callback в onKill | 205.16 ms/итер | 4,874 опер/сек |
| Очистка хранилища ассоциаций (all.this.clear) | 2.18 s/итер | 0,459 опер/сек |

### Сравнительный анализ

- Наибольшие затраты ресурсов происходят при операциях создания и удаления большого количества ассоциаций
- Перезагрузка ассоциаций (reload) работает эффективнее, чем отдельные операции onKill и onNew
- Использование пользовательских обработчиков незначительно влияет на производительность

### Возможные оптимизации

1. **Пакетная обработка**: Добавление механизма пакетного создания/удаления ассоциаций
2. **Отложенная очистка**: Использование механизма отложенной очистки для удаленных ассоциаций
3. **Оптимизация хранилища**: Использование более эффективных структур данных для хранения живых ассоциаций

## Основные компоненты

### all

`all` — хранилище всех живых ассоциаций в системе, реализованное как ассоциация с Set:

```javascript
import { all } from 'deep7';
```

### a.kill()

Функция для удаления ассоциации из системы жизненного цикла:

```javascript
import deep from 'deep7';
const a = deep();

// Удалить ассоциацию
a.kill();
```
