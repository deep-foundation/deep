# Lifecycle

Класс, отвечающий за управление жизненным циклом ассоциаций, контролирующий их создание и уничтожение. `Lifecycle` поддерживает кэширование ассоциаций, их уникальность и автоматическое освобождение ресурсов при уничтожении.

## Производительность

| Тест | Среднее время выполнения | Операций в секунду |
|------|--------------------------|--------------------|
| Основной: Создание ассоциации + onNew | 500000.00 µs/итер | 2 опер/сек |
| Основной: Создание и удаление ассоциации (onNew + onKill) | 500000.00 µs/итер | 2 опер/сек |
| Основной: Вызов функции kill | 500000.00 µs/итер | 2 опер/сек |
| Основной: Перезагрузка ассоциации (reload) | 4950.50 µs/итер | 202 опер/сек |
| Основной: Получение количества живых ассоциаций (all.this.size) | 5102.04 µs/итер | 196 опер/сек |
| Основной: Пользовательский callback в onNew | 45454.55 µs/итер | 22 опер/сек |
| Основной: Пользовательский callback в onKill | 55555.56 µs/итер | 18 опер/сек |
| Основной: Очистка хранилища ассоциаций (all.this.clear) | 1000000.00 µs/итер | 1 опер/сек |

## Основные компоненты

### all

`all` — хранилище всех живых ассоциаций в системе, реализованное как ассоциация с Set:

```javascript
import { all } from 'deep7';
```

### a.kill()

Функция для удаления ассоциации из системы жизненного цикла:

```javascript
import deep from 'deep7';
const a = deep();

// Удалить ассоциацию
a.kill();
```
