# Lifecycle

Класс, отвечающий за управление жизненным циклом ассоциаций, контролирующий их создание и уничтожение. `Lifecycle` поддерживает кэширование ассоциаций, их уникальность и автоматическое освобождение ресурсов при уничтожении.

[Результаты бенчмарков →](./LIFECYCLE.benchmark.md)

## Основные компоненты

### all

`all` — хранилище всех живых ассоциаций в системе, реализованное как ассоциация с Set:

```javascript
import { all } from 'deep7';

// Проверка наличия ассоциации в системе
all.has(a.this); // true, если ассоциация жива
```

### a.kill()

Функция для удаления ассоциации из системы жизненного цикла:

```javascript
import deep from 'deep7';
const a = deep();

// Удалить ассоциацию
a.kill();
```

### a.isAlive()

Функция для проверки, является ли ассоциация "живой" (присутствует в all):

```javascript
import deep from 'deep7';
const a = deep();

// Проверить, жива ли ассоциация
a.isAlive(); // true, если ассоциация в all, иначе false
```

## Жизненный цикл ассоциации

1. **Создание** - При создании экземпляра Association через конструктор или функцию `deep()`, ассоциация автоматически регистрируется в хранилище `all`
2. **Использование** - Ассоциация доступна в системе и может быть найдена через `all` или функции поиска
3. **Удаление** - Вызов метода `a.kill()` удаляет ассоциацию из системы и освобождает связанные ресурсы

## Особенности реализации

- Система поддерживает автоматическое добавление в `all` при создании экземпляра Association
- Несколько экземпляров Association с одинаковым значением `this` добавляют это значение в `all` только один раз
- При удалении одной из нескольких ассоциаций с одинаковым `this`, значение удаляется из `all`
- События `add` и `delete` генерируются при добавлении и удалении ассоциации из `all`
- Метод `isAlive()` позволяет проверить, зарегистрирована ли ассоциация в системе

## Внутренние методы

Для внутреннего использования в системе предусмотрены следующие методы:

- `_onNew()` - вызывается при регистрации ассоциации в системе
- `_onKill()` - вызывается при удалении ассоциации из системы
