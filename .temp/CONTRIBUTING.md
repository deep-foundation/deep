# Руководство по разработке репозитория

## Правила

### При обновлении методов:
- Всегда обновлять сводные таблицы совместимости методов с типами в соответствующих *.md файлах.
- Всегда следить что все варианты применения методы протестированы в *.test.js и проверены на разных объемах в *.benchmark.js

### Производительность
- В названии должно быть буквальное обозначение типов сущностей с группировкой по количеству элементов, без лишней риторики
