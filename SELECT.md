# Select

Метод `select` предоставляет мощный механизм для фильтрации ассоциаций на основе объекта-выражения. Он позволяет выполнять поиск и фильтрацию ассоциаций по различным критериям, таким как тип, источник, назначение, значение и другие отношения.

[Результаты бенчмарков →](./SELECT.benchmark.md)

## Основные особенности

- **Фильтрация по множеству критериев**: поиск ассоциаций по типу, источнику, назначению, значению и их комбинациям
- **Инвертированные отношения**: поддержка обратных связей (type/typed, from/out, to/in, value/valued)
- **Отслеживание изменений**: автоматическое обновление результатов при изменении исходных данных
- **Пустой объект выражения**: возвращает все существующие ассоциации
- **Предстоящая возможность:** вложенные выражения для сложных запросов

## Синтаксис

```javascript
const result = deep.select(expression);
```

где `expression` - объект, описывающий критерии поиска.

## Объект-выражение

Объект-выражение содержит ключи, представляющие типы отношений, и значения, представляющие конкретные ассоциации или примитивные значения для поиска.

### Поддерживаемые ключи

| Ключ | Описание |
|------|----------|
| `type` | Поиск ассоциаций с указанным типом |
| `typed` | Поиск типа для указанной ассоциации |
| `from` | Поиск ассоциаций с указанным источником |
| `out` | Поиск ассоциаций, исходящих из указанного источника |
| `to` | Поиск ассоциаций с указанным назначением |
| `in` | Поиск ассоциаций, входящих в указанное назначение |
| `value` | Поиск ассоциаций с указанным значением |
| `valued` | Поиск значения для указанной ассоциации |
| `this` | Поиск конкретной ассоциации по значению (не может быть экземпляром Association) |

### Пустой объект выражения

Если в метод `select` передать пустой объект `{}`, то результатом будет множество, содержащее все существующие ассоциации в системе. Это эквивалентно доступу к глобальной ассоциации `all`, но с дополнительной возможностью отслеживания изменений через `.track`.

```javascript
// Получение всех ассоциаций в системе
const allAssociations = deep.select({});
```

## Примеры использования

### Основные примеры

```javascript
// Поиск ассоциаций по типу
const typeA = deep();
const result1 = deep.select({ type: typeA });

// Поиск по источнику
const source = deep();
const result2 = deep.select({ from: source });

// Поиск по назначению
const target = deep();
const result3 = deep.select({ to: target });

// Поиск по значению
const value = deep();
const result4 = deep.select({ value: value });

// Получение всех ассоциаций в системе
const allAssociations = deep.select({});
```

### Комбинирование условий

```javascript
// Поиск ассоциаций, удовлетворяющих нескольким условиям
const result = deep.select({
  type: typeA,
  from: source,
  to: target
});
```

Все условия в объекте-выражении объединяются операцией логического И (AND).

### Отслеживание изменений

```javascript
// Создание результата поиска
const result = deep.select({ type: typeA });

// Включение отслеживания изменений
const tracker = result.track;

// При изменении типа у какой-либо ассоциации или создании/удалении ассоциаций,
// множество result.this будет автоматически обновляться

// Прекращение отслеживания изменений
tracker.kill();
```

### Использование с пустым объектом выражения и отслеживание

```javascript
// Получение всех ассоциаций
const all = deep.select({});

// Активация трекера
const tracker = all.track;

// Создание новой ассоциации
const newAssoc = deep();

// all.this уже содержит newAssoc.this

// Удаление ассоциации
newAssoc.kill();

// all.this уже не содержит newAssoc.this

// Отключение трекера
tracker.kill();
```

## Принципы работы

1. Объект-выражение парсится, и для каждого ключа вызывается соответствующий обработчик
2. Каждый обработчик возвращает множество ассоциаций, соответствующих условию
3. Все полученные множества пересекаются с помощью операции AND
4. Результат оборачивается в новый экземпляр Association
5. При активации трекера, результат автоматически обновляется при изменениях в исходных данных

## Совместимость

Метод `select` полностью совместим с остальными методами библиотеки Deep, включая:

- События (`on`, `emit`)
- Манипуляции с множествами (`add`, `delete`)
- Связи (`type`, `from`, `to`, `value`)
